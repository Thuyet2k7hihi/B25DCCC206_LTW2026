# Bài thực hành 01 - Quản lý điểm sinh viên

Ứng dụng React đáp ứng yêu cầu bài thực hành:

- Hiển thị ít nhất 3 sinh viên mẫu.
- Thêm sinh viên mới, giữ nguyên dữ liệu cũ.
- Kiểm tra họ tên/lớp không để trống và điểm từ 0 đến 10.
- Xóa sinh viên.
- Lọc sinh viên Giỏi (điểm >= 8) hoặc Trượt (điểm < 5).
- Thống kê tổng số sinh viên và điểm trung bình.
- Chia component: `App`, `StudentList`, `StudentItem`.
- Sử dụng `const`/`let`, Arrow Functions, Destructuring, Template Literals và `map`/`filter`/`reduce`.

## Chạy project

Cần Node.js.

```bash
npm install
npm run dev
```

Sau đó mở địa chỉ Vite hiển thị trong terminal.
